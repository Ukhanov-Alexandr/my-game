# Зеркала и луч

Оригинальная браузерная головоломка на клетчатом поле. На поле стоит фонарь и испускает луч света. Поворачивай зеркала так, чтобы луч осветил **все кристаллы**. Кристалл луч не останавливает — он пропускает его дальше, поэтому одним лучом можно зажечь сразу несколько.

**Играть: https://ukhanov-alexandr.github.io/my-game/**

Работает на компьютере и на телефоне.

## Что внутри

- **12 уровней** — от простых к сложным.
- **«Уровень дня»** — новый уровень каждый день. Он строится прямо в браузере по дате (UTC), поэтому у всех игроков в один и тот же день он одинаковый. Сервер и расписания (cron) не нужны.
- Звук (Web Audio), который можно выключить.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Двигать курсор | стрелки или W/A/S/D | свайп по полю |
| Повернуть зеркало | пробел или Enter | тап |
| Включить/выключить звук | клавиша M (или кнопка 🔊) | кнопка 🔊 |
| В меню | Esc (или кнопка ←) | кнопка ← |

## Запуск на своём компьютере

Игра — это обычные статические файлы: без сборки и без `npm install`. Но она использует ES-модули, а они **не работают при открытии через `file://`** (двойным кликом по `index.html`). Нужен любой статический сервер. Например, если установлен Python:

```bash
python3 -m http.server 8000
```

или Node.js:

```bash
npx serve .
```

После этого открой http://localhost:8000/.

## Тесты

Тесты написаны на встроенном в Node.js `node --test`, зависимости ставить не нужно (CI использует Node.js 22). Все тестовые файлы лежат в `tests/` и называются `*.test.js`:

```bash
node --test $(find tests -name '*.test.js')
```

## CI и автодеплой

- `.github/workflows/tests.yml` — запускает все тесты на каждом pull request и на каждом push.
- `.github/workflows/pages.yml` — при push в `main` сначала прогоняет тесты, и только если они прошли, публикует игру на GitHub Pages. В публикацию попадают только файлы игры (без `tests`, `docs`, `.github`).

Для автодеплоя в настройках репозитория должно быть выбрано: Settings → Pages → Source: «GitHub Actions».

## Устройство проекта

```
index.html, style.css   страница и оформление
src/core/               правила игры: луч, поворот зеркал, проверка победы, решатель
src/levels/             12 готовых уровней
src/daily/              генератор «уровня дня» по дате
src/ui/                 отрисовка на canvas и ввод (клавиши, тапы, свайпы)
src/audio/              звук
tests/                  тесты по папкам src/
docs/architecture.md    подробное описание
```

Главный принцип: правила игры — чистые функции без DOM, отдельно от отрисовки, поэтому их легко проверять тестами. Подробности — в [docs/architecture.md](docs/architecture.md).
